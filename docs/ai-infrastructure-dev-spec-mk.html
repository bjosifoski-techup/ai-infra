Преглед

Резиме на проектот

Посебен инфраструктурен ангажман кој ја проширува платформата Emerico AI Commerce Platform со три компоненти. LiteLLM е распореден на управуван облак Elestio и поврзан со самохостираниот LLM на клиентот, со автентикација преку Keycloak JWT и ограничување на брзина по ниво. Осум MCP сервери се конфигурирани преку API-портата Zuplo, покривајќи три dropshipping партнери и пет патнички и билетарски партнери, со алатки автоматски генерирани од OpenAPI спецификации и ограничување на брзина управувано на ниво на портата.

MongoDB Atlas ги хостира краткорочните и долгорочните слоеви на меморија за разговори, при што сите читања и запишувања се ограничени по корисник преку Keycloak JWT. Сите три компоненти делат наменска Keycloak инстанца распоредена на Elestio специјално за идентитетот на корисниците на Commerce Platform, одделена од реалмот на SSO проектот.

Обем

Три компоненти

LiteLLM Proxy

Унифицирана LLM-порта распоредена на управуван облак Elestio. Ги валидира Keycloak JWT-токените, ги спроведува ограничувањата на брзина по ниво, го мапира RBAC од тврдења за улоги и ги насочува барањата кон самохостираниот модел на клиентот.

MCP Servers via Zuplo

Осум MCP сервери конфигурирани во Zuplo, покривајќи три dropshipping партнери (AliExpress, BigBuy, CJDropshipping) и пет патнички/партнерски партнери (Travelpayout, Ticketmaster, Eventbrite, Viator, StubHub). Алатките се автоматски генерирани од OpenAPI спецификации каде е достапно.

MongoDB Memory

Слој на меморија хостиран на Atlas со краткорочни (подвижен прозорец на разговорот) и долгорочни (преференции, резимеа, историја на купувања) шеми. Сите прашалници се ограничени со Keycloak JWT корисничкото ID.

Надворешни системи

Интеграции

Keycloak Identity Provider

Свежа наменска инстанца распоредена на Elestio. Издава JWT за идентитет на корисниците, го спроведува RBAC преку тврдења за улоги и обезбедува MFA. Ја користат LiteLLM, Zuplo и MongoDB за автентикација и ограничување на опсег на корисниците.

LiteLLM ↔ Keycloak

Интеграција на JWKS крајна точка за валидација на JWT. Ограничување на брзина по ниво (Guest, Free, Silver, Gold, Platinum) и RBAC преку Keycloak тврдења за улоги.

LiteLLM ↔ Self-hosted LLM

Поврзување со крајната точка на самохостираниот модел на клиентот, со конфигурација базирана на околина и зацврстување на безбедноста.

AliExpress Open Platform

MCP сервер за пребарување, филтрирање и детали на производи. Алатките се автоматски генерирани од OpenAPI спецификација.

BigBuy REST API

MCP сервер за пребарување, филтрирање и детали на производи. Алатките се автоматски генерирани од OpenAPI спецификација.

CJDropshipping API

MCP сервер за пребарување, филтрирање и детали на производи. Алатките се автоматски генерирани од OpenAPI спецификација.

Travelpayout

MCP сервер кој обезбедува партнерски длабоки врски со параметри за следење.

Ticketmaster

MCP сервер за пребарување, филтрирање на настани и генерирање партнерски длабоки врски.

Eventbrite

MCP сервер за пребарување, филтрирање на настани и генерирање партнерски длабоки врски.

Viator

MCP сервер за пребарување, филтрирање на искуства и генерирање партнерски длабоки врски.

StubHub

MCP сервер за пребарување, филтрирање на билети и генерирање партнерски длабоки врски.

MongoDB Atlas

Облак кластер кој ги хостира краткорочните и долгорочните слоеви на меморија, ограничени по корисник преку Keycloak JWT.

MCP-UI client

Интеграција на клиент за прикажување на резултати од алатки вратени од MCP серверите во интерфејсот за разговор.

Инфраструктура

Хостирање и оперативно поставување

  • LiteLLM прокси распореден на управуван облак Elestio (еднокликна LiteLLM распоредба)
  • Zuplo API Gateway кој ги хостира сите 8 MCP сервери со мајчинска MCP поддршка
  • MongoDB Atlas кластер за складирање меморија со оптимизирани индекси за пребарувања ограничени на корисник
  • Интеграција на Keycloak JWKS крајна точка низ LiteLLM, Zuplo и меморијските API-и
  • Ограничување на брзина по корисничко ниво на ниво на LiteLLM и портата
  • JWT посредник за ограничување на опсегот на корисниците спроведен на секое читање и запишување на меморија
  • Конфигурација базирана на околина за сите API клучеви, крајни точки и тајни
  • Зацврстување на безбедноста низ сите три компоненти (LiteLLM, Zuplo, меморијски API-и)

Ограничување на брзина

Ограничувања на брзина по ниво

LiteLLM спроведува ограничувања на брзина по Keycloak корисничко ниво. RBAC е мапиран од Keycloak тврдења за улоги.

Guest

Најниска горна граница на ограничување на брзина во LiteLLM.

Free

Повисоко ограничување на брзина, регистриран корисник.

Silver

Платено ниво со зголемени ограничувања на брзина.

Gold

Платено ниво со високи ограничувања на брзина.

Platinum

Платено ниво со највисоки ограничувања на брзина.

Важно

Забелешки и зависности

Наменска Keycloak инстанца

Свежа Keycloak инстанца е распоредена на Elestio специјално за оваа инфраструктура. Таа е одделена од SSO проектот и управува само со идентитетот на корисниците на Commerce Platform.

Сложеноста на MCP алатките зависи од квалитетот на OpenAPI спецификацијата

Партнерите со чисти OpenAPI спецификации овозможуваат автоматски генерирани алатки. Партнерите без нив ќе бараат рачна дефиниција на алатки. Редоследот на градба во Фаза 3 треба да даде приоритет на партнерите со најчистите спецификации прво, за да се открие варијансата во напорот порано.

Ниво на Zuplo план

Zuplo планот мора да поддржува функции за MCP сервери. Потврдете го нивото на планот пред почетокот на Фаза 3.

Независна кодна база

Овој ангажман не зависи од кодната база на Emerico AI Commerce Platform. Компонентите можат да бидат развиени, распоредени и тестирани независно и интегрирани во Commerce апликацијата преку конфигурирани крајни точки.
